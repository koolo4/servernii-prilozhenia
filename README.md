# Арканополис: Хартия нового мира

**Техномагическая сборка о городе, который становится машиной.**

| | |
|---|---|
| **Minecraft** | 1.20.1 |
| **Загрузчик** | Forge 47.x |
| **Формат** | Длительное прохождение в одиночку или небольшой командой |
| **Упор** | Развитие поселения (MineColonies), автоматизация, квестовая прогрессия по эпохам |
| **Статус** | `0.1.0-alpha` — каркас сборки, требуется совместный тест перед публикацией |

## Идея

Игрок развивает не отдельную фабрику, а самодостаточную колонию:

- **MineColonies** — население, профессии, строительство и городская инфраструктура. Уровень города открывает эпохи.
- **Create** — ранняя автоматизация, транспорт и паровая энергетика.
- **Thermal Series и Mekanism** — промышленность, переработка руд и энергетика.
- **Ars Nouveau, Botania, Blood Magic, Eidolon: Repraised** — магические реагенты, материалы и ритуальная прогрессия.
- **Applied Energistics 2** — централизованное хранение и автоматические производственные заказы.

Каждая технологическая эпоха требует двух типов достижений: **городских** (ратуша, здания, жители, исследования университета) и **производственных** (запущенные цепочки и контрольные партии продукции). Прогрессия идёт не по принципу «накопи ресурсы», а через развитие самого города.

## Быстрый старт

1. **Лаунчер**: установите Minecraft 1.20.1 и Forge 47.x (например, через Prism Launcher / GDLauncher / официальный лаунчер).
2. **Моды**: скачайте jar-файлы в папку `mods/`:

   **Windows — самый простой способ:** двойной щелчок по файлу **`Скачать_моды.bat`** в корне репозитория.
   Окно не закроется само — будет виден весь процесс и результат.

   **Windows (из открытого PowerShell):**
   ```powershell
   powershell -ExecutionPolicy Bypass -File tools\download_mods.ps1
   ```

   **Linux / macOS / Git Bash:**
   ```bash
   python3 tools/download_mods.py --manifest mods/mods.json --out mods/
   ```

   > Не запускайте `.py`/`.ps1` двойным щелчком напрямую: Windows открывает мимолётное окно, скрипт не находит файлы и окно закрывается. Используйте `Скачать_моды.bat` или команду в открытом PowerShell. Если Python установлен в Windows — используйте `python` или `py` (не `python3`, это заглушка Microsoft Store).

   Либо скачайте моды вручную по списку из [`docs/03-mods.md`](docs/03-mods.md) (ссылки на CurseForge/Modrinth).
3. **Конфигурация**: скопируйте папки `kubejs/`, `config/` и `defaultconfigs/` в папку инстанса (туда же, куда положены моды).
4. Запустите игру, создайте мир и откройте книгу квестов (кнопка FTB Quests в инвентаре или `FTB Quests` в меню).

> **Project MMO**: оверлей со списком навыков слева сверху по умолчанию скрыт (файл `config/pmmo-client.toml`), а фейерверки за повышение навыков отключены (`defaultconfigs/pmmo-Perks.toml`; для существующих миров файл нужно один раз скопировать в `<мир>/serverconfig/` — см. комментарий в самом файле). Навыки смотреть кнопкой Project MMO в инвентаре. При обновлении сборки перекопируйте `config/`, `kubejs/` и `defaultconfigs/` заново — иначе настройки и скрипты останутся старыми.

> ⚠️ **Важно**: сборка находится в статусе alpha. Комбинация модов на одной версии Minecraft не гарантирует стабильность без совместного теста. Перед публикацией выполните [`docs/06-testing.md`](docs/06-testing.md).

## Ключевые принципы баланса

1. **Колония — условие развития.** Открытие Mekanism требует не только стали, но и ратуши III уровня, университета, продовольственной инфраструктуры и склада с курьером.
2. **Не переписывать стройматериалы MineColonies.** Основные стройматериалы остаются доступными, иначе возникает цикл: «для следующей эпохи нужен университет, а для университета — материалы следующей эпохи».
3. **Дорого — значит сложно организовать.** Хороший дорогой рецепт требует нескольких производственных линий, мощности, автоматизации, городской инфраструктуры и редкого, но возобновляемого компонента. Плохой — 50 000 одинаковых слитков.
4. **Каждая магическая школа — своя специализация**, а не обязательный набор всех модов для каждого предмета. Школы объединяются в ключевых корпусах, управляющих компонентах и эндгейм-проектах.

## Эпохи (кратко)

| Эпоха | Название | Ключевой проект |
|---|---|---|
| Пролог | Право на поселение | Ратуша I, первые жители, еда |
| I | Дерево, вода и ремесло | Автоматизированные строительные компоненты (Create) |
| II | Пар и логистика | Городская мастерская пластин и шестерней |
| III | Механизмы и индустриальный город | Полная цепочка переработки руды, сталь, усиленные корпуса |
| IV | Расцвет магии | Городская арканная лаборатория (4 школы) |
| V | Сеть и автоматизация | AE2-производство «от руды до корпуса» |
| VI | Космический горизонт | **Сердце Арканополиса** — финальный городской артефакт |
