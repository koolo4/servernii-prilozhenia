# Changelog

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).

## [0.1.1-alpha] — 2026-10-12

### Добавлено
- `Скачать_моды.bat` — запуск загрузки двойным щелчком (ASCII, без ошибок cmd).
- Каскад источников в загрузчике: Modrinth → Maven (FTB) → GitHub → CurseForge (cfwidget). Теперь скачивается всё автоматически.
- Закреплён **Create 0.5.1.f** (аддоны сборки рассчитаны на 0.5.1; не обновлять до 6.x).

### Исправлено
- PowerShell 5.1: `System.Object[]` вместо номеров версий (разбор ответа API).
- Кириллица в .bat ломала запуск (`'загрузка' is not recognized`).
- Скрипты находят файлы репозитория независимо от рабочей папки.

## [0.1.0-alpha] — 2026-10-12

### Добавлено
- Полная концепция сборки «Арканополис: Хартия нового мира» (`docs/`).
- Манифест модов `mods/mods.json` с закреплёнными версиями для Minecraft 1.20.1 / Forge 47.x.
- Инструменты загрузки модов: `tools/download_mods.py` (Python) и `tools/download_mods.ps1` (Windows PowerShell, без Python).
- KubeJS: 12 кастомных предметов прогрессии и рецепты эпох I–VI (`kubejs/`).
- FTB Quests: 13 глав (пролог, 6 эпох, 5 необязательных глав, справочник) (`config/ftbquests/`).
- Текстуры предметов и документация по тестированию и серверу.

### Примечание
- Это первая рабочая версия «каркаса» сборки. Версии модов закреплены по
  состоянию на 2026-10-12; перед публикацией обязателен совместный прогон
  (см. `docs/06-testing.md`).
