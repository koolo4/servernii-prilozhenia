# Чек-лист контроля перед публикацией

Наличие модов на одной версии Minecraft не гарантирует стабильность комбинации. Перед релизом выполните все пункты и зафиксируйте результаты.

## 1. Фиксация версий

- [ ] Зафиксировать версии Forge, Minecraft и каждого jar-файла (сверить с `mods/mods.json`).
- [ ] Сохранить список полученных файлов (`tools/download_mods.py --report`) в релизные заметки.
- [ ] Проверить, что отсутствуют дубликаты модов и не стоит отдельный Flywheel.

## 2. Чистый запуск

- [ ] Запустить чистый клиент на свежем инстансе, убедиться в отсутствии ошибок загрузки.
- [ ] Создать новый мир, дождаться полной генерации.
- [ ] Проверить время загрузки и потребление памяти (ModernFix/FerriteCore работают).

## 3. Колония (MineColonies)

- [ ] Поставить ратушу, возвести хижину строителя, принять первого жителя.
- [ ] Прокачать ратушу до II и III уровней (проверить доступность всех материалов построек!).
- [ ] Построить склад, университет; нанять курьера; проверить доставку.
- [ ] Убедиться, что кастомные рецепты **не блокируют** строительные материалы MineColonies.

## 4. Квесты (FTB Quests)

- [ ] Открыть книгу квестов: все 13 глав на месте, русские названия и описания отображаются.
- [ ] Проверить цепочку зависимостей: эпохи открываются последовательно.
- [ ] Пройти пролог: Городская хартия выдаётся.
- [ ] Проверить выдачу всех печатей в ключевых квестах.
- [ ] Убедиться, что необязательные главы открываются независимо.

## 5. Рецепты (KubeJS)

- [ ] `/kubejs errors` — нет ошибок скриптов; `/kubejs dump` — все 12 предметов `arcanopolis:` зарегистрированы.
- [ ] В JEI проверить каждый кастомный рецепт (состав, количество, результат).
- [ ] Сверить ID Eidolon (`pewter_ingot`, `arcane_gold_ingot`) — при необходимости исправить скрипты.
- [ ] Проверить, что переходные крафты **расходуют** печати, а без печати рецепт недоступен.
- [ ] Проверить отсутствие обходных путей (дублирующие рецепты других модов).
- [ ] Пройти все обязательные крафты в одиночной игре.

## 6. Прогрессия эпохами

- [ ] Эпоха I: водяные колёса, пресс, пила работают; самоцветы источника добываются.
- [ ] Эпоха II: паровой двигатель + линии Create; железная дорога/конвейеры.
- [ ] Эпоха III: полная цепочка переработки руды (Thermal + Mekanism), сталь, усиленные корпуса.
- [ ] Эпоха IV: все 4 магические школы дают базовые компоненты; Ars Creo связывает Ars Nouveau и Create.
- [ ] Эпоха V: AE2-сеть, шаблоны, автоматические заказы, Applied Mekanistics.
- [ ] Эпоха VI: Изначальный катализатор, Сердце Арканополиса, финальный квест.

## 7. Автоматика (долгие прогоны)

- [ ] Create: линии работают ≥ 2 часов без рассинхронизации/утечек сущностей.
- [ ] Mekanism/Thermal: энергоснабжение стабильно, переполнения буферов нет.
- [ ] AE2: авто-крафт нескольких компонентов подряд, тикеты не зависают.
- [ ] Колония получает материалы без ручной доставки игроком (курьеры + склад).

## 8. Сервер (если предусмотрен)

- [ ] Развернуть сервер по `docs/07-server.md`, клиент подключается.
- [ ] Квесты синхронизируются в команде (FTB Teams).
- [ ] Проверить обязательные крафты и прогрессию на сервере.
- [ ] Настроить бэкапы, лимиты чанков (FTB Chunks — опционально).

## 9. Визуал и интерфейс

- [ ] Jade/JourneyMap/JEI работают без конфликтов с Embeddium.
- [ ] Текстуры кастомных предметов отображаются (в т.ч. на сервере).
- [ ] Проверить FPS на средней машине; при необходимости — настройки ModernFix.

## Известные зоны риска

| Зона | Что проверять в первую очередь |
|---|---|
| Create + аддоны | Аддоны чувствительны к версии Create (6.0.9) — не обновлять по одному |
| Eidolon: Repraised | Убедиться, что jar именно для Forge 1.20.1 |
| Thermal + Mekanism + Create | Конфликты рецептов/тегов (Almost Unified, Polymorph) |
| MineColonies + любые моды блоков | Здания и шаблоны (Structurize/Domum Ornamentum) |
| Optifine/Rubidium | Не устанавливать — конфликт с Embeddium/Create |
