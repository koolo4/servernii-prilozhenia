## Суммарные риски и как гасим

1. **Тройное масштабирование мобов** (Majrusz × Champions × Scaling Health) — главный
   риск: HP может раздуться в «губки». Гасим настройками: потолки, медленный рост,
   шанс элиток 3–5% (фаза конфигов после первого теста).
2. **Сильный лут из структур** (WDA/Cataclysm/Relics/«древние инструменты» TiCon) может
   дать снаряжение раньше эпохи. Это снаряжение, а не компоненты: открыть Mekanism/AE2
   раньше ворот им нельзя, «контрольные партии» квестов — предметы производства, их
   лутом не закроешь. Принимаем как награду за риск.
3. **Project MMO + FTB Ultimine**: перк массовой добычи PMmo пересекается с Ultimine —
   Ultimine у нас опциональный (required: false), конфликта в ядре нет.
4. **Производительность**: +5 контентных модов к ~70. Новые структуры (WDA/Cataclysm)
   дорожают генерацию чанков при исследовании — для сервера желательна предгенерация
   окрестностей (см. `docs/07-server.md`). ModernFix/Embeddium уже стоят.

## Tinkers' Construct: запрещать ли «крутое» до уровня персонажа?

Разобрался — **запрет по уровню персонажа технически не работает и не нужен**:

- **Почему не PMmo**: у Tinkers' один ID предмета на вид инструмента («клинок»),
  а материал — это NBT внутри предмета. PMmo смотрит требования по ID, поэтому
  различить «деревянный клинок» и «маньюллиновый» он не может — только запретить все
  клинки сразу, что бессмысленно.
- **Что делаем вместо этого — гейт эпохами, как весь пак** (`90_era_gating.js`):
  - свободно с эпохи I–II: дерево/камень/медь/бронза/железо и слизневые материалы —
    это честная стартовая персоналка;
  - сталь TiCon ничего не добавляет сверх нашей эпохи III — свободно;
  - кобальт и ардит лежат в Незере (портал эпохами не закрыт) — это экспедиционный
    риск, а не обход машинных ворот;
  - **единственная точка, которую закрываем**: сплав маньюллина. Переносим его на
    жар 1500 (топливо «пылающая кровь» вместо лавы 1000) — нужна развитая плавильня
    и Незер-инфраструктура; альтернатива на фазе 3 — катализатор из компонента
    эпохи III. Реализуется заменой одного датапак-рецепта через KubeJS.
  - вершина модификаторов (алмаз/незерит) и так требует ресурсы эпох V–VI.
- Умеренные требования Project MMO при этом не дублируют гейт, а задают личный темп:
  ванильные алмазные инструменты попросят навык, а тинкер-альтернатива растёт
  материалом. Это нормальная развилка, а не дыра.

## Квесты по новым модам — нужны, но только бонусные

Ворота эпох не трогаем (правило аудита: эпохи нельзя запирать за бой/гринд). План
при перестройке книги (одобренная структура из `docs/09`):

| Контент | Куда | Как детектим |
|---|---|---|
| Боссы Cataclysm (по одному на босса) | гл. 71 «Экспедиции», бонусная ветка | нативная задача FTB `kill` по сущности |
| Данжи When Dungeons Arise | гл. 71, ветка рядом с боссами | задачи на структуру/достижение |
| Первая реликвия; 5 разных реликвий | гл. 71 + секретный квест | наша JS-проверка «любой предмет из списка» (уже умеем: `item_any`) |
| Убийство чемпионов ранга 3+ | секретный «Убийца чемпионов» | событие смерти в KubeJS + проверка NBT чемпионов (фаза 3 — проверить теги) |
| Плавильня, первая отливка, маньюллиновый клинок | бонусные листья эпох II–III | предметные задачи на `tconstruct:*` |
| Вехи навыков PMmo (25/50) | бонус-глава прогрессии | через API PMmo из KubeJS — фаза 3 (R&D); если API не даст — квестов не будет, у PMmo свой понятный GUI |

## Порядок проверки у вас (5 минут)

1. `Скачать_моды.bat` → смотреть строки по новым модам (`[OK]`), особенно Relics и
   Cataclysm (у них нестандартные slug — уже исправлены в манифесте, но проверяем факт).
2. Новый мир (старый тоже можно, но структуры/руда появятся только в новых чанках),
   эпоха 0–I: не душит ли старт (PMmo + чемпионы), открывается ли книга Tinkers'.
3. Дойти до Незера, глянуть кобальт; `/reload` ошибок KubeJS быть не должно.
