# Структура квестбука

Квестбук реализован на FTB Quests (файлы в `config/ftbquests/quests/`). Восемь основных глав (пролог + шесть эпох + финал внутри эпохи VI), пять необязательных глав и справочник.

## Группы глав

| Группа | Главы |
|---|---|
| **Основная линия** | Пролог → Эпохи I–VI |
| **Необязательные главы** | Архитекторы, Экспедиции, Магистры школы, Инженерные задачи, Город без дефицита |
| **Справочник** | Механики сборки, кастомные предметы, условия эпох |

## Основная линия

### Пролог. «Право на поселение»
Стартовые задачи: площадка, снабжение, ратуша I, хижина строителя, жильё, еда, обучение заказам. Награда: **Городская хартия**. Побочные ветки: «первые ремёсла».

### Эпоха I. «Дерево, вода и ремесло»
Ветка города (ратуша II, 8 жителей, лесоруб, шахтёр, склад, курьер, еда) и ветка Create (водяное колесо, валы, пресс, пила, вентилятор). Ветка Ars Nouveau (книга заклинаний, источник). Ключевой квест: автоматизированное производство компонентов → **Печать ремесленников**.

### Эпоха II. «Пар и логистика»
Латунная автоматизация, паровой двигатель, Steam 'n' Rails, университет. Ключевой проект: городская мастерская компонентов. Ключевой квест: централизованное снабжение → **Печать пара**.

### Эпоха III. «Механизмы и индустриальный город»
Две параллельные ветки: Thermal (переработка, энергия) и Mekanism (обогащение, сплавы, газы). Городская ветка: ратуша III, 20 жителей, исследования. Ключевые квесты: полная цепочка переработки, партия усиленных корпусов, подключение к складу → крафт **Технического паспорта**.

### Эпоха IV. «Расцвет магии»
Четыре независимые ветки школ (Ars Nouveau, Botania, Blood Magic, Eidolon) плюс объединяющая ветка «Арканная лаборатория». Каждая школа: базовое достижение + одна продвинутая задача. Ключевой квест: лаборатория + компоненты школ → **Печать расцвета**.

### Эпоха V. «Сеть и автоматизированное производство»
Ветка AE2 (сеть, ячейки, шаблоны), ветка интеграций (Applied Mekanistics), ветка автоматических заказов. Ключевой проект: «от руды до корпуса» → крафт **Ядра автоматизации** → **Печать сети**.

### Эпоха VI. «Космический горизонт»
Поздние линии Mekanism/Thermal, редкие реагенты школ, подготовка центрального сооружения. Финальная цепочка: Изначальный катализатор → **Сердце Арканополиса** → установка в центре колонии → финальный квест.

## Необязательные главы (независимое открытие)

| Глава | Содержание | Награды |
|---|---|---|
| **Архитекторы** | Комплекты зданий, декоративные кварталы, оформление центра | Декоративные наборы, инструменты |
| **Экспедиции** | Структуры, данжи, редкие биомы, поиск материалов | Снаряжение, сундуки |
| **Магистры школы** | Глубокие испытания каждой магической школы | Уникальные компоненты школ |
| **Инженерные задачи** | Альтернативные схемы фабрик, транспортные сети, энергомосты | Инженерные наборы |
| **Город без дефицита** | Испытание: снабжение колонии без участия игрока (N игровых дней) | Финальная награда-трофей |

## Справочник
Информационные квесты (задачи-галочки и «checkmark»): как работают печати, где брать материалы эпох, как устроены кастомные рецепты, чек-лист городских условий.

## Типы задач и наград

| Тип | Где используется |
|---|---|
| `item` (задача) | «Получите/сделайте предмет» — большинство квестов; предметы не расходуются задачей |
| `checkmark` (задача) | Городские условия MineColonии («Ратуша III уровня», «20 жителей») — подтверждается игроком |
| `item` (награда) | Печати, хартия, ресурсы, инструменты |
| `choice` (награда) | Необязательные главы — выбор из набора |

## Правила зависимостей

1. Каждая эпоха зависит от ключевого квеста предыдущей (цепочка допусков).
2. Внутри эпохи ветки города и технологий открываются параллельно, но ключевой квест требует обеих.
3. Необязательные главы не зависят от эпох (открываются с пролога), но их сложность растёт по мере прохождения.
4. Линии зависимостей (`hide_dependent_lines`) включены там, где цепочка длинная.

## Формат файлов

```
config/ftbquests/quests/
├── data.snbt              — глобальные настройки книги (название сборки, форма квестов)
├── chapter_groups.snbt    — группы глав
└── chapters/
    ├── 00_prologue.snbt
    ├── 10_epoch_wood_water.snbt
    ├── 20_epoch_steam_logistics.snbt
    ├── 30_epoch_industry.snbt
    ├── 40_epoch_magic.snbt
    ├── 50_epoch_network.snbt
    ├── 60_epoch_cosmos.snbt
    ├── 70_side_architects.snbt
    ├── 71_side_expeditions.snbt
    ├── 72_side_schools.snbt
    ├── 73_side_engineering.snbt
    ├── 74_side_supply.snbt
    └── 80_reference.snbt
```

Файлы сгенерированы `tools/gen_quests.py` (единообразные ID, корректный SNBT) и могут дорабатываться в игре через редактор квестов FTB Quests (`/ftbquests editing_mode`).

## Как работает выполнение (v0.3.9)

**Ручная отметка запрещена.** Никакая задача больше не является «галочкой» (checkmark): прогрессия использует только автоматически проверяемые типы задач:

- **item** — задача выполняется сама при получении предмета (крафт, добыча, торговля). Пример: «Ратуша II уровня» не кликается — подходит только реальное условие.
- **custom** — условие проверяет серверный скрипт `kubejs/server_scripts/95_colony_checks.js` (генерируется `tools/gen_quests.py`): уровень ратуши (`townhall:N`), число жителей (`citizens:N`), наличие построек (`building:слово:N`). Проверка — раз в 5 секунд; при выполнении условий скрипт сам выдаёт прогресс через FTB Quests API. Попытка кликнуть задачу не даёт ничего.
- Несколько обучающих задач («изучить механику») помечены `custom/always` — они выполняются автоматически и не блокируют эпохи.

**Жёсткие эпохи.** Глава эпохи N+1 имеет chapter-level зависимость от главы эпохи N: пока в текущей эпохе не выполнены **все** квесты, следующая глава закрыта (серым), и переход невозможен. Цепочка: Пролог → I → II → III → IV → V → VI. Необязательные главы (70–74) и справочник независимы.

**Гейтинг механизмов.** `kubejs/server_scripts/90_era_gating.js` не даёт крафтить механизмы поздних эпох раньше времени: рама машин Thermal и базовые контуры Mekanism требуют `create:precision_mechanism` (эпоха II), высшие контуры Mekanism — `arcanopolis:arcane_converter` (эпоха IV). Там же — дорогие рецепты восстановления печатей (цепочка ремесленники → пар → аркана → сеть).

**Аварийная разблокировка** (опечатка в условии и т.п.): `/ftbquests change_progress <ник> complete <id-задачи>` — id видны в режиме редактирования.

Количество: 13 глав, **123 квеста**. Генерация и правки условий — в `tools/gen_quests.py` (таблица `TASK_MAP`); после правок запустите `python3 tools/gen_quests.py` — главы и `95_colony_checks.js` пересоберутся вместе.
