# Развёртывание сервера

## Требования

- **Java 17** (обязательно для Minecraft 1.20.1).
- 6–8 GB RAM (рекомендуется 8–10 GB при колонии 30+ жителей и работающих линиях).
- Одинаковый набор модов на сервере и у клиентов (кроме модов `[C]` из `docs/03-mods.md`).

## Установка

1. Скачайте установщик Forge **1.20.1 — 47.x** и разверните сервер:
   ```bash
   java -jar forge-1.20.1-47.x.x-installer.jar --installServer
   ```
2. Согласитесь с `eula.txt` (`eula=true`).
3. Скопируйте в папку сервера:
   - все моды из `mods/mods.json` **без клиентских** (`[C]`: Embeddium, AppleSkin, Mouse Tweaks, Entity Culling);
   - папки `kubejs/` и `config/` из этого репозитория.
4. Запуск:
   ```bash
   java -Xms4G -Xmx8G -jar forge-1.20.1-47.x.x.jar nogui
   ```

## Состав для сервера (исключения)

| Мод | Причина исключения |
|---|---|
| Embeddium | только клиентский рендер |
| AppleSkin | клиентская информация |
| Mouse Tweaks | клиентский QoL |
| Entity Culling | клиентский рендер |

JourneyMap и Jade ставятся на обе стороны (серверная часть нужна для синхронизации).

## Настройка

### `server.properties`
```
view-distance=8            # начните с 8–10, поднимайте по нагрузке
simulation-distance=8
allow-flight=true          # Create-конструкции и JourneyMap
motd=Арканополис: Хартия нового мира
```

### FTB Teams / квесты
- Прогресс квестов общий у команды: игроки в одной команде (FTB Teams) видят общий прогресс.
- Для раздельного прохождения включите отдельные команды при входе (настройки FTB Teams).

### Производительность
- Выделите ≥ 6 GB под JVM; используйте Aikar's Flags (G1GC) для длинных сессий.
- ModernFix уже в наборе — не дублируйте оптимизационные моды.
- MineColonies генерирует много сущностей: ограничьте размер колонии в настройках мода при слабом железе.

### Бэкапы
- Колония и AE2-сеть критичны к потерям: бэкапируйте `world/` минимум раз в день (например, `restic`/`borg` по расписанию).
- Храните `config/` и `kubejs/` в git — это и есть конфигурация сборки.

## Тикеты и защита

- Для командного сервера рассмотрите **FTB Chunks** (территории колонии) — не входит в обязательный набор.
- Краш-эксплойты: запретите `opencontainers`/взрывчатку в чужих регионах на уровне защиты (FTB Chunks или плагины прокси).

## Обновление сборки

1. Обновляйте моды только после сверки `mods/mods.json` и прогона тестов (`docs/06-testing.md`).
2. Create и его аддоны обновляются **только вместе**.
3. После обновления kubejs/quests перезапустите сервер и выполните `/kubejs errors`, `/ftbquests` (режим редактирования выключен).
