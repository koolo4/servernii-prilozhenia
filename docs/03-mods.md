# Состав модпака

Список проектов с выпусками для **Minecraft 1.20.1 / Forge 47.x**. Это не гарантия совместимости любых случайно скачанных файлов: перед публикацией закрепите версии (уже сделано в `mods/mods.json`) и проведите совместный тест (`docs/06-testing.md`).

Обозначения: **[B]** — и на клиент, и на сервер; **[C]** — только клиент; **[S]** — только сервер (опционально).

Загрузка всех модов одной командой: `python3 tools/download_mods.py --manifest mods/mods.json --out mods/`

## Что сознательно НЕ входит в сборку

| Мод / категория | Причина |
|---|---|
| Rubidium | Конфликтует с Embeddium — выбран Embeddium |
| Optifine | Конфликтует с Embeddium/Create/Flywheel |
| EMI / REI | Дублируют JEI — оставлен один просмотрщик |
| Отдельный Flywheel | Встроен в Create 6.x |
| Thaumcraft | Нет на 1.20.1 — заменён Ars Nouveau / Botania / Blood Magic / Eidolon |
| Apotheosis | Аффиксовый лут ломает экономику эпох; роль элитных мобов закрывает Champions |
| GregTech, Industrial Foregoing, Refined Storage | Смещают фокус сборки; AE2 закрывает нишу хранения |

## Порядок установки библиотек

1. Forge 47.x → 2. Architectury API, Curios, GeckoLib, Patchouli, Bookshelf, Rhino → 3. FTB Library, FTB Teams, FTB Quests → 4. MineColonies-стек → 5. Create и аддоны → 6. Mekanism-модули → 7. Thermal-модули → 8. AE2 и Applied Mekanistics → 9. Магические моды → 10. KubeJS и аддоны → 11. Оптимизация и интерфейс → 12. Сложность и прогрессия персонажа (Mantle до Tinkers' Construct; Curios уже стоит для Relics).

Точные файлы (имена jar) смотрите в `mods/mods.json` — скрипт `tools/download_mods.py` подставит их автоматически.
